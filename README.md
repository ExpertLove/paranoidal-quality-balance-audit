# Paranoidal — аудит бонусов качества (15.10.2026)

Сайт: https://expertlove.github.io/paranoidal-quality-balance-audit/

Интерактивный отчёт о том, как качество (Quality, ic-more-qualities, режим `full`) усиливает постройки, модули и оборудование сборки Paranoidal на Factorio 2.0.77: где бонусы на ступенях 5–10 ломают баланс.

- Вкладки: главные находки, тепловая карта (810 строк «объект × характеристика» × 46 качеств), графики, «обгон старших моделей», подбор кривой с черновиком Lua, экспорт задачи (Markdown/JSON).
- Источник: статический расчёт по дампу данных игры (ветка `qulity_doc`) и формулам `QualityPrototype` из prototype-api 2.0.77 плюс скрипты модов (ветряки, РИТЭГ, Factorissimo).
- Игрой не проверялось. Строки «предположение» и вкладка «Не посчитано» показывают границы расчёта.

Один файл `index.html`, работает без сети. Отметки для экспорта хранятся в браузере.
